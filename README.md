# 🐟 Fish Species Identification System for Fish Markets

This project is a bilingual (English/Sinhala) AI-powered fish species identification system designed to help users — especially in Sri Lanka — recognize and learn about fish sold in local markets. Users can upload a photo of a fish, and the system will identify the species and display relevant details such as nutrition facts, seasonal availability, and freshness indicators.

---

## 📸 Use Case

In many Sri Lankan fish markets, identifying fish species correctly can be difficult due to regional name differences or lack of awareness. This system helps:

- ✅ General consumers make informed choices
- ✅ Tourists understand what they are buying
- ✅ Vendors label fish correctly
- ✅ Promote awareness about sustainable fishing practices

---

## 🚀 Features

- 🧠 **AI-based image recognition** using a custom-trained CNN
- 🌐 **Multilingual support**: English 🇬🇧 and Sinhala 🇱🇰 (language toggle)
- 🐠 **Detailed fish profile** with:
  - Description and habitat  
  - Nutrition facts (protein, fat, omega-3)  
  - Freshness indicators (gills, firmness, smell)  
  - Seasonal availability and price range
- 📱 Simple and responsive web interface

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (with Bootstrap)
- **Backend:** Python Flask
- **AI Model:** TensorFlow/Keras (trained on a custom dataset)
- **Model Deployment:** TensorFlow Lite / Keras H5
- **Image Handling:** OpenCV / PIL
